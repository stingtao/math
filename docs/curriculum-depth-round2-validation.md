# 第二輪內容補強：本機驗收紀錄

日期：2026-09-08。本輪新增 24 課的能力切片、72 個能力目標、144 道題目。兩輪累計 48 課、144 個能力目標及 288 道新增題，完整題庫共 1,634 題。尚未部署。

## 內容與範圍

每個能力有兩個變式；每課含運算、表示及推理／應用三類能力。每題提供個別提示、解析、迷思及難度，範例使用不同於練習題的案例。原題及第一輪內容未改動。

G7–G9 的新能力包括反推百分比、三角形限制、抽樣偏差、不放回機率、函數表示／比較、立體對角線、條件比例、單位與精度、絕對值解集、線性－二次系統及模型假設。G10–G12 補充相似推理、條件機率與獨立性、分類資料、有理／對數方程、三角圖形、常態分布、連續性、鏈鎖律、定積分及抽樣分布。

本機 Demo 完成以下實際操作：

- G11 新三角圖形：390 像素手機及 1,440 像素桌面均正常；手機四張圖各約 300 像素，0／π／2π 與 −5／0／5 清楚、讀屏名稱完整，無橫向溢出。
