## 驗證範圍與剩餘缺口

- 72 課只表示每課指定的三個能力有成對題目證據。181 課尚未逐能力審核；不是完整課綱達成率。各課剩餘缺口見[完整報告](curriculum-depth-report.md)。
- 自動儲存測試在套用專案遷移的獨立 SQLite 測試庫執行，不使用正式家庭學習資料。
- 瀏覽器驗證使用 Demo，無建立或更動正式學習帳戶；因此不宣稱已用真實帳戶完成整套正式登入、練習及複習流程。
- 複習仍依當下到期佇列產生題組；跨分頁或佇列變更可能要求重新開啟，不是持久保存的複習快照。
- 既有複習載入 API 失敗仍可能呈現空佇列。本輪不宣稱已改善這項錯誤呈現；三個已發行題庫版本均保留支援。

部署方式依據 [Cloudflare Wrangler deploy 文件](https://developers.cloudflare.com/workers/wrangler/commands/workers/#deploy)：先 dry-run，使用已完成驗證的建置產物部署，並透過 keep-vars 保留控制台變數。
